# Autonomo2_Torres_Joel
## Sistema de Promedios - Fundamentos de Programación - Joel Torres

### 📌 Descripción del Proyecto
Sistema desarrollado en Python para la gestión de notas de estudiantes, aplicando estructuras lógicas (condicionales) y repetitivas (bucles), con control de versiones en GitHub.

### 🚀 Paso 1: Configuración de GitHub
- Creación de cuenta y repositorio `Autonomo2_Torres_Joel`
- Configuración de Git global (`git config`)
- Control de versiones con `add, commit, push`
- **Diagrama:** `DIAGRAMA DE GIT HIB.png`

### 💻 Paso 2: Desarrollo del Programa
**Funcionalidades principales:**
1.  Registro de estudiantes con validación de notas (0-10)
2.  Cálculo de promedio: `suma / 3`
3.  Determinación de estado:
    - `>= 7` = Aprobado
    - `>= 5` = Supletorio
    - `< 5` = Reprobado
4.  Menú interactivo con bucle `while True`
5.  Listado de estudiantes registrados

**Estructuras aplicadas:**
- **Condicionales:** `if/elif/else` para validar notas y estado
- **Repetitivas:** `for` para pedir 3 notas, `while` para menú y validación
- **Funciones:** `calcular_promedio()`, `obtener_estado()`, `registrar_estudiante()`
- **Estructuras de datos:** Listas y diccionarios
